## 定位与MVP

“留白”面向个人本地安排：用一句中文发起请求，助手自行查询或追问，把实际操作变成一张可核对的确认卡。价值是自然表达、正确匹配和可解释的真实结果，不以复杂排期算法或视觉效果为主。

主要用户：需要快速记录/查找/修改计划的个人；需要现场说明 Agent 设计并证明实际状态的演示者。MVP包含单次日程 CRUD、模糊检索、澄清、冲突建议和重启保留。多人协调、真实邀请、周期排期和外部同步暂不提供。

## 用户旅程

| 场景 | 主要流程 | 成功条件 |
|---|---|---|
| 创建明确安排 | 中文描述 → 模型提案 → 完整卡片 → 确认 | 右侧出现事件，回执从数据库读回 |
| 不完整安排 | 描述 → 缺日期/开始/时长的定向问题 → 补充 → 提案 | 前文主题保留，不要求整句重输 |
| 查询 | 模型选择范围/关键词 → 工具 → 真实事件列表 | 无结果也明确说明；截断时提示缩小范围 |
| 修改 | 检索候选 → 唯一匹配/用户选择 → 展示原值与新值 → 确认 | 只改指定记录和字段 |
| 删除 | 检索 → 必要时消歧 → 展示具体记录 → 确认删除 | 仅删除所选记录，其他保留 |
| 时间冲突 | 校验原请求 → 冲突事实及已验证方案 → 稳定ID选择/自定义 → 统一提案确认 | 没有覆盖已有安排，没有偷偷改时间 |

## 页面结构

页眉是名称、模型状态和新对话。左侧包括简洁说明、聊天记录、澄清消息、待确认卡、歧义候选卡、工具摘要与输入框；右侧包括日程计数、时区、日期过滤和日程卡片。手机宽度变为上下排列。

输入为自由中文文本，Enter发送、Shift+Enter换行，中文输入法组合状态下不误发送。处理中锁定输入和写入按钮；错误作为可见消息保留。内容按文本渲染，事件标题和备注中的HTML不会执行。

工具摘要只展示“检索日程/寻找空档/准备修改”等及状态，不显示模型思维链、秘密或完整内部上下文。页面还显示后端实际运行model ID，用于识别环境覆盖是否生效；“已配置”只代表存在配置，不承诺联网已连通。

## 多轮与确认体验

缺少标题、日期、开始或时长时，LLM选择缺项，程序生成中文定向问题；用户可只回答缺失信息。最近12轮持久化，即使重启仍能继续。换天后相对日期以新一轮真实时刻重新解释；复杂跨日续聊建议补充明确日期。

全部写入都要确认，不把“模型说好了”视为提交。确认卡展示目标标题、完整日期起止、地点备注；修改还展示原值。取消不会变更日程。新消息表示新意图，使旧提案失效；提案15分钟超时。用户最终确认必须使用按钮，聊天中“确认”不直接授权写入，避免把模糊回复当批准。

候选多于一个时，模型不能随意选ID。用户可点击候选卡或补充日期使检索唯一；点击卡片只为下一模型回合选择目标，回合内重新搜索仅在目标ID/版本仍一致时保留选择；之后仍需核对确认，后续新任务不继承选择。多条删除逐条确认，避免一条模糊指令清空日历。

## 冲突与恢复

冲突信息来自真实工具；没有执行空档搜索时不能声称无空档，助手需补做校验/空档工具。已校验时列出占用日程或可用时段；用户选择替代时间后重新提案。不提供强制覆盖按钮；只有显式核实条件的可暂停/并行活动允许重叠。确认时发现新冲突或记录已修改，显示未执行并要求重新查询，保护旧版本数据。

模型未配置时保留网页与日程查看，提示配置步骤；不会使用隐藏规则引擎伪装 LLM。网络、认证、限流、模型格式错误分别给出可操作提示。超时后停止本轮，不伪报成功；HTTP不自动重试。浏览器断线可刷新，持久化提案与实际日程能恢复。

## 离线演示的边界

独立入口、明显黄色提示和“模型替身”状态。只重放公开的固定示例，禁止把它当任意自然语言能力演示。日历操作和确认是真实实现；每次新演示可指定新的数据库。普通模式可随时换成真实 provider，不需要更改页面与业务逻辑。

## MVP验收

中文界面可从缺信息推进到真实确认；创建、查询、修改、删除完整；同名不误删；冲突给出事实和建议；重复点击不重复操作；重启可恢复日程/会话/提案。离线自动化和浏览器均验证了上述主流程。真实模型效果、现场面试和GitHub分享属于后续外部验收。

## 本轮冲突面板

同一对话展示事件卡片、约束、精确交集、时区、推荐理由、其他方案及未核实假设。方案按钮提交稳定ID，前端不组装写操作。单行输入支持Enter；加载时禁用，错误可见；统一提案列出每条调整前后，确认后才原子写入。取消可回到方案继续自定义。固定预约不被自动移动；无可行方案时明确要求补充可调整条件。外部预约状态未核实，所有回执只承诺本地修改。

## 当前默认交互

一句话多项安排先保留独立草稿，缺字段只问具体事件；用户澄清暂停/并行继续同一任务。地点未知不是继承另一事件地点的理由。默认冲突视图压缩为短摘要、名字与精确重叠、一个推荐与短理由、采用按钮、其他方案入口、单行自定义；约束、假设和前后对照在详情可见。必要条件未知仍窄问，真正硬冲突不隐藏。确认仍核对完整统一变更，不降低验证。窄屏实际截图及验证边界见本轮验收。

## 批量取消与恢复

“取消今天/本周全部”展示真实范围、清单、数量、勾选框、确认及取消，不逐条追问。取消勾选立即经服务器更新精确选择，新提案才可确认；歧义的保留对象未明确前禁止确认。新请求不自动继承旧排除。

取消后仅活动日历隐藏；回收站显示原时间、删除和到期时间，可单项/整批准备恢复。最近删除显示一键撤销，绑定本会话原操作；有冲突停在明确子集选择，正常恢复需确认，无模型自行写入。恢复保留原时间，不覆盖占用。7天过期拒绝恢复；不加永久删除按钮与后台清理设施。详细实际截图及范围见本轮验收。
