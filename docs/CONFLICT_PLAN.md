# 冲突处理实施计划

本轮在既有 Agent/provider 上扩展，不解析中文硬编码路由。

1. 数据与事务：兼容迁移 JSON 属性列；确定性半开区间事实；最终集合校验与单事务批量写入、读回、幂等回执。
2. 方案服务：会话持久化冲突上下文、版本快照、稳定方案 ID；少量不同方案、显式假设、点击重验。
3. 工具与会话：新增严格批量提案工具，保留旧工具；上下文携带新事件与旧事件版本。明确 nested patch 参数错误。
4. 前端：同一对话内事件/重叠/方案卡片、自定义输入、统一确认和回滚状态。
5. 验证：隔离 SQLite A–H、既有回归、浏览器与最多30次 DeepSeek 请求；日志和文档如实记录。

默认重要性、灵活性和可打断性均 unknown。固定时间/keep_time 为硬约束；不从标题猜测。允许嵌套需要可暂停外层或显式并行、双方 overlap_allowed、同一非空地点、明确已核验注意力及通勤（coexistence_verified）。否则仍阻止重叠，要求澄清。暂不实现拆分自动优化与外部预约同步。
